# 5. 노션 데이터베이스 스키마 및 동기화 (Notion Schema & Sync)

본 문서는 연동된 노션 채용 관리 데이터베이스(**`🗃️ 공고 분석`**, Database ID: `343831b8-54df-8081-adb8-e6c93fc69e37`)의 18개 표준 속성 매핑 규칙과 페이지 본문 템플릿, 그리고 동기화 도구([tools/notionJobPublisher.js](../tools/notionJobPublisher.js))를 기술합니다.

---

## 5.1 노션 18개 표준 속성 명세 및 입력 규칙

| 속성명 (Property) | 노션 타입 | 입력 값 규격 및 에이전트 처리 지침 |
| :--- | :--- | :--- |
| **기업명** | `title` | 회사명 (예: `토스뱅크`, `당근`) |
| **채용직무** | `rich_text` | 공고에 명시된 상세 포지션 명칭 |
| **직무분류** | `select` | `프론트엔드 개발자`, `웹 개발`, `백엔드 개발자`, `풀스택 개발자`, `SW개발`, `데이터 엔지니어` 등 |
| **경력조건** | `select` | `신입`, `경력무관`, `1년+`, `3년 미만`, `3년+`, `5년이하 (신입가능)` 등 |
| **고용형태** | `select` | `정규직`, `채용연계형 인턴`, `체험형 인턴`, `계약직` 등 |
| **산업군** | `select` | `IT/웹통신`, `핀테크`, `이커머스`, `B2B / SaaS`, `스타트업` 등 1차 분류 |
| **산업군 (상세)** | `rich_text` | 회사의 구체적 비즈니스 도메인 |
| **회사규모** | `select` | `대기업`, `중견기업`, `스타트업`, `벤처기업`, `중소기업` 등 |
| **근무지** | `rich_text` | 회사 위치 및 근무 형태 (예: `서울 강남구 테헤란로 (하이브리드)`) |
| **채용링크** | `url` | 원본 채용공고 URL (**고유 식별 키로 사용**) |
| **마감일** | `date` | 마감일자 (`YYYY-MM-DD`, 상시채용인 경우 비워둠) |
| **공고 등록일** | `date` | 공고가 게시된 날짜 (`YYYY-MM-DD`) |
| **상태** | `status` | 기본값: **`미지원`** |
| **AI 수집** | `checkbox` | 에이전트 자동 수집 식별을 위해 **`true (체크)`** |
| **제출 서류** | `multi_select` | `이력서`, `포트폴리오`, `자기소개서` 등 |
| **전형 절차 (1차 ~ 6차)** | `select` | 공고 본문에서 추출한 1~6차 전형 단계 (`서류전형`, `코딩테스트`, `직무면접`, `임원면접` 등) |
| **매력도** | `select` | **항상 비워둠 (None)** (사용자가 직접 주관적 평가를 내릴 수 있도록 공란 유지) |
| **created_at** | `date` | 노션 페이지 등록 일시 |

## 5.2 페이지 본문 레이아웃 및 아이콘

1. **페이지 기본 아이콘**:
   - 빌딩을 상징하는 **🏢 이모지 아이콘** 자동 부착.
2. **AI 3줄 요약 콜아웃 블록**:
   - 페이지 최상단에 **블루 배경의 💡 콜아웃 블록**으로 배치.
   - React, TypeScript, 프론트엔드 역량 및 신입 성장성 관점의 3가지 핵심 지원 포인트를 기록.
3. **상세 요강 섹션**:
   - 주요 업무 (`📋 주요 업무`)
   - 자격 요건 (`🎯 자격 요건`)
   - 우대 사항 (`✨ 우대 사항`)
   - 혜택 및 복지 (`🎁 혜택 및 복지`)

## 5.3 노션 발행 유틸리티 도구 ([tools/notionJobPublisher.js](../tools/notionJobPublisher.js))

에이전트는 정제된 공고 JSON 객체(단일 또는 배열)를 아래 명령어로 즉시 노션 DB에 등록할 수 있습니다:

```bash
# 단일 공고 JSON 전달 및 등록
node tools/notionJobPublisher.js '{"company":"토스뱅크", "position":"프론트엔드", ...}'

# 임시 파일 경로 전달
node tools/notionJobPublisher.js scratch/approvedJobs.json
```
* 등록 성공 즉시 노션 페이지 URL을 반환하며, 디스코드 알림을 자동으로 트리거합니다.
