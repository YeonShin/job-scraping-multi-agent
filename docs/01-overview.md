# 1. 시스템 개요 (System Overview)

## 1.1 프로젝트 정의 및 비전
본 프로젝트는 **Google Antigravity IDE 네이티브 멀티 에이전트 시스템**을 기반으로, 주요 채용 플랫폼(사람인, 잡코리아, 원티드)의 공고를 지능적으로 탐색·심사하여 **노션(Notion) 채용 관리 데이터베이스에 표준화된 18개 속성과 AI 3줄 요약으로 자동 등록하고, 디스코드(Discord)로 일일 리포트를 전송하는 완전 자동화 파이프라인**입니다.

사용자가 대화창에서 명령("채용공고 찾아줘")하거나 특정 공고 URL을 전달하면, 총괄 오케스트레이터와 전문 서브에이전트들이 공고를 수집 및 심사하여, 최적의 맞춤 채용공고 리포트를 바로 검토할 수 있는 원클릭 경험을 제공합니다.

## 1.2 기존 크롤러 vs Antigravity 네이티브 멀티 에이전트

| 구분 | 레거시 하드코딩 스크래퍼 (기존 방식) | Antigravity 멀티 에이전트 시스템 (현재) |
| :--- | :--- | :--- |
| **아키텍처** | 단일 스크립트/함수 내 if문 및 정규식 처리 | 대화창 Chief Orchestrator가 플랫폼별 전문 서브에이전트 지휘 |
| **탐색 방식** | 단순 텍스트 키워드 검색 (`stext='프론트엔드'`) | 기업 규모별 **듀얼 트랙(Dual-Track) 카테고리 필터링** |
| **사이트 UI 개편 대응** | 셀렉터 변경 시 파싱 에러 발생 | 접근성 트리 및 브라우저 도구(`browser_subagent`) 기반 자율 적응 |
| **통이미지/배너 공고** | 텍스트 부재로 수집 불가 | 스크린샷 캡처 및 멀티모달 Vision 판독 |
| **심사 및 자격 판별** | 규칙 기반 단순 단어 매칭 | 본문 문맥 분석, 1~6차 전형 분해, React/TS 중심 3줄 요약 |
| **운영 방식** | 수동 터미널 실행 또는 복잡한 설정 필요 | **대화창 온디맨드 자연어 오케스트레이션** |

## 1.3 핵심 목표 (Key Objectives)

1. **듀얼 트랙(Dual-Track) 직무 카테고리 탐색**
   - 트랙 1: 대기업·중견기업 대상 IT 개발 직군 / 트랙 2: 기업규모 무관 프론트엔드·웹개발 (정의는 [job-criteria.md](../.agents/rules/job-criteria.md))
2. **비용 및 속도 최적화 (Fast Passthrough & Deduplication)**
   - 노션 DB 사전 캐시 대조 및 scanController 사전 필터링을 통해 이미 등록된 공고는 즉시 스킵.
   - 마감 후 재오픈된 공고는 자동 감지하여 재수집 허용.
3. **노션 템플릿 규격화 및 디스코드 리포트**
   - 18개 표준 속성 정확 매핑, `매력도`는 사용자 직접 평가를 위해 공란 유지.
   - 수집 및 심사 완료 후 Discord Webhook으로 일일 수집 결과 실시간 전송.
4. **온디맨드 자연어 실행 (On-Demand Execution)**
   - 대화창 명령을 통한 플랫폼 전체 자동 탐색(모드 A) 및 단일 공고 URL 직통 등록(모드 B) 즉시 지원.
