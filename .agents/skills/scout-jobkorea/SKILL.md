# Jobkorea Scout Sub-Agent

잡코리아 플랫폼의 직무별 채용정보(`menucode=duty`)에서 기업 형태와 직무 범위에 맞춘 **2가지 분기(Dual-Track) 탐색 전략**을 수행합니다.

---

## 1. 듀얼 트랙 탐색 규격 및 URL

### [분기 1] 대기업 / 중견기업 / 매출1000대 / 30대그룹사 / 강소기업 트랙
* **기업 형태**: 대기업(`1`), 30대그룹사(`2`), 매출1000대기업(`3`), 중견기업(`4`), 강소기업(`5`) (`cotype=1,2,3,4,5`)
* **직무 범위**: AI·개발·데이터 주요 개발 직군 전체
  - 백엔드개발자 (`1000229`), 프론트엔드개발자 (`1000230`), 웹개발자 (`1000231`), 앱개발자 (`1000232`), 시스템엔지니어 (`1000233`), 소프트웨어개발자 (`1000239`), 웹퍼블리셔 (`1000245`), AI서비스개발자 (`1000423`)
* **경력 조건**: 신입 (`career=1`) 및 경력무관 (`career=8`)
* **공식 탐색 URL**:
  `https://www.jobkorea.co.kr/recruit/joblist?menucode=duty&duty=1000229,1000230,1000231,1000232,1000233,1000239,1000245,1000423&career=1,8&cotype=1,2,3,4,5`

### [분기 2] 중소기업 / 벤처기업 / 코스피 / 코스닥 트랙
* **기업 형태**: 중소기업(`15`), 벤처기업(`7`), 코스피상장(`11`), 코스닥상장(`12`) (`cotype=15,7,11,12`)
* **직무 범위**: 웹개발자 (`1000231`), 프론트엔드개발자 (`1000230`), 웹퍼블리셔 (`1000245`)
* **경력 조건**: 신입 (`career=1`) 및 경력무관 (`career=8`)
* **공식 탐색 URL**:
  `https://www.jobkorea.co.kr/recruit/joblist?menucode=duty&duty=1000230,1000231,1000245&career=1,8&cotype=15,7,11,12`

## 2. 공고 목록 타깃팅 및 광고 배제 (토큰·비용 최적화)
> 🚨 **[광고 필터링 필수]** 잡코리아 목록 상단의 스페셜/포커스 배너 광고는 필터와 무관한 공고가 섞여 있어 불필요한 토큰과 시간을 소모합니다.  
> 반드시 **일반 채용공고 리스트 영역인 `<div id="dev-gi-list">` 내부의 공고만 탐색**하십시오!

* **타깃 컨테이너**: `<div id="dev-gi-list">` (`#dev-gi-list`)
* **공고 식별**: 해당 컨테이너 내부의 `a[href*="GI_Read/"]` 태그를 통해 공고 고유 식별자 파싱.
* **상세 요강 접근**:
  `https://www.jobkorea.co.kr/Recruit/GI_Read/{id}`

---

## 3. 작업 절차 (Sub-Agent Workflow)
1. **브라우저 기반 목록 탐색**:
   - `browser_subagent` 또는 Playwright MCP 도구(`browser_navigate`)를 가동하여 분기 1(대기업 SW전체)과 분기 2(중소/상장 웹·FE·퍼블리셔) URL로 순차 진입합니다.
   - 상단의 스페셜/포커스 광고 영역을 건너뛰고, 오직 **`<div id="dev-gi-list">` (일반 채용공고 리스트)** 내부의 공고 링크(`a[href*="GI_Read/"]`)만 수집합니다.
2. **중복 필터링**:
   - `notion-job-sync`의 기존 등록 캐시와 대조하여 이미 등록된 URL은 건너뜁니다.
3. **상세 본문 브라우징 및 심사**:
   - `browser_navigate` 또는 `browser_subagent`로 상세 페이지(`GI_Read/{id}`)에 진입하여 자격 요건, 우대 사항, 전형 단계를 파싱합니다.
   - 통이미지/배너 공고의 경우 `browser_screenshot`으로 캡처 후 문맥을 판독합니다.
   - **심사 기준**:
     * 대기업/그룹사: 일반 SW개발/시스템/AI 포지션도 합격.
     * 중소/벤처: 반드시 웹 프론트엔드, 웹 풀스택, 퍼블리셔 포지션이어야 합격 (순수 백엔드 탈락).
     * 공통: 최소 경력 2년 이상 요구 시 즉시 탈락.
4. **전형 절차 분해**: 1차~6차 채용 단계 추출 (`서류전형`, `코딩테스트`, `면접전형` 등).
5. **노션 등록 위임**: 심사 통과 건을 `notion-job-sync` 스킬을 통해 노션 DB에 등록합니다.
