# Notion Job Sync Skill

채용공고 데이터를 사용자의 노션 채용 관리 데이터베이스 규격에 완벽하게 일치시켜 등록하고 중복을 방지하는 가이드입니다.

## 1. 노션 데이터베이스 연동 정보
* **DATABASE_ID**: `.env`의 `NOTION_DATABASE_ID` 참조
* **아이콘 규칙**: 반드시 `🏢` (빌딩 이모지) 부착

## 2. 노션 데이터베이스 18개 표준 속성 규격

| 속성명 | 타입 | 값 형식 및 유효 옵션 예시 | 비고 |
| :--- | :--- | :--- | :--- |
| **기업명** | `title` | 텍스트 (예: `당근`, `토스뱅크`) | 필수 (페이지 제목) |
| **채용직무** | `rich_text` | 텍스트 (예: `Frontend Developer`) | 필수 |
| **채용링크** | `url` | 원본 채용공고 URL | 필수 (중복 체크 키) |
| **상태** | `status` | `미지원` | 등록 시 기본값 |
| **AI 수집** | `checkbox` | `true` (`__YES__`) | AI 자동 등록 식별용 |
| **created_at** | `date` | `YYYY-MM-DD` | 수집 일자 |
| **직무분류** | `select` | `프론트엔드`, `풀스택`, `웹개발`, `소프트웨어` | 주 직무 분류 |
| **경력조건** | `select` | `신입`, `경력무관`, `신입/경력` | 경력 조건 |
| **고용형태** | `select` | `정규직`, `계약직`, `인턴`, `전환형 인턴` | 고용 형태 |
| **산업군** | `select` | `IT/소프트웨어`, `핀테크`, `커머스`, `게임` 등 | 대분류 |
| **산업군 (상세)** | `rich_text` | 텍스트 (예: `B2B SaaS 솔루션`) | 세부 설명 |
| **회사규모** | `select` | `스타트업`, `중소기업`, `중견기업`, `대기업` | 회사 규모 |
| **근무지** | `rich_text` | 텍스트 (예: `서울 강남구 테헤란로 (재택 병행)`) | 근무 위치 |
| **마감일** | `date` | `YYYY-MM-DD` (상시 채용이면 비워둠) | 마감 일정 |
| **공고 등록일** | `date` | `YYYY-MM-DD` (알 수 없으면 비워둠) | 최초 등록일 |
| **제출 서류** | `multi_select`| `이력서`, `포트폴리오`, `자기소개서`, `깃허브` | 필수 제출 항목 |
| **1차 ~ 6차** | `select` | `서류전형`, `코딩테스트`, `과제테스트`, `직무면접`, `컬쳐핏면접`, `임직원면접`, `최종합격` | 전형 단계별 매핑 |
| **매력도** | `select` | **항상 비워둠 (None)** | 사용자가 직접 평가 |

## 3. 페이지 본문 블록 구성 (Notion Markdown)

등록되는 각 공고 페이지의 본문은 다음과 같이 구성합니다:

```markdown

> • [지원 적합도]: React/TypeScript 기반 신입 개발자에게 매우 적합한 주니어 채용입니다.
> • [핵심 업무]: 사내 백오피스 및 고객 대면 웹 프론트엔드 기능 개발 및 컴포넌트 고도화.
> • [어필 포인트]: 디자인 시스템 구축 경험 및 반응형 웹 인터랙션 경험을 강조하면 유리합니다.
```

## 4. 중복 방지 규칙 (Deduplication Rules)
1. **URL 정규화**:
   - `utm_source`, `utm_medium`, `tracking_id`, `ref` 등의 트래킹 파라미터를 제거한 표준 URL로 대조합니다.
2. **이중 매칭**:
   - 1차: 정규화된 `채용링크` URL 대조
   - 2차: `기업명 + 채용직무` 조합 대조 (URL이 변경된 경우 방어)
3. **재오픈 판정 (Reopened)**:
   - 기존 노션 DB의 해당 공고 상태가 `마감`인 경우, 다시 채용이 재개된 것이므로 **신규 재공고로 수집을 허용**합니다.
   - 상태가 `미지원`, `서류 작성 중`, `서류 제출 완료` 등 활성 상태인 경우 중복 스킵합니다.
