# Notion Job Sync Skill (참조 규격)

이 문서는 노션 채용 관리 데이터베이스의 **표준 속성 규격 및 본문 블록 레이아웃**을 정의하는 참조 문서입니다.

> 🚨 **[역할 안내]**
> * 중복 검증, 캐시 대조, 노션 DB 등록(레이트 리밋 350ms 준수), 실패 재시도 관리는 에이전트가 직접 하지 않고 **`tools/jobFilter.js` 및 `tools/publishRun.js`가 코드로 전담**합니다.
> * 심사 에이전트는 [`.agents/skills/job-reviewer/SKILL.md`](../job-reviewer/SKILL.md)의 규격대로 JSON을 추출하여 `tools/reviewQueue.js submit`으로 제출하기만 하면 됩니다.

---

## 1. 노션 데이터베이스 연동 정보
* **DATABASE_ID**: `.env`의 `NOTION_DATABASE_ID`
* **페이지 아이콘**: 반드시 `🏢` (빌딩 이모지) 부착

---

## 2. 노션 데이터베이스 표준 속성 규격

| 속성명 | 타입 | 값 형식 및 유효 옵션 예시 | 비고 |
| :--- | :--- | :--- | :--- |
| **공고키** | `rich_text` | 고유 키 (예: `saramin:55201338`, `wanted:12345`) | 시스템 고유 식별자 |
| **기업명** | `title` | 텍스트 (예: `당근`, `(주)그린에스텍`) | 필수 (페이지 제목) |
| **채용직무** | `rich_text` | 텍스트 (예: `Frontend Developer`) | 필수 |
| **채용링크** | `url` | 원본 채용공고 URL | 필수 |
| **상태** | `status` | `미지원` | 등록 시 기본값 |
| **AI 수집** | `checkbox` | `true` | AI 자동 등록 식별용 |
| **created_at** | `date` | `YYYY-MM-DD` | 수집 일자 |
| **직무분류** | `select` | `프론트엔드`, `풀스택`, `웹개발`, `소프트웨어`, `시스템엔지니어`, `SW개발`, `백엔드`, `앱개발` | 주 직무 분류 |
| **경력조건** | `select` | `신입`, `경력무관`, `신입/경력` | 경력 조건 |
| **고용형태** | `select` | `정규직`, `계약직`, `인턴`, `전환형 인턴`, `채용연계형 인턴`, `체험형 인턴` | 고용 형태 |
| **산업군** | `select` | `IT/소프트웨어`, `핀테크`, `커머스`, `게임`, `스마트팩토리` 등 | 대분류 |
| **산업군 (상세)** | `rich_text` | 텍스트 (예: `스마트팜 IoT 플랫폼`) | 세부 설명 |
| **회사규모** | `select` | `스타트업`, `중소기업`, `중견기업`, `대기업`, `공기업`, `외국계기업`, `대기업계열사`, `벤처기업` | 회사 규모 |
| **근무지** | `rich_text` | 텍스트 (예: `서울 송파구 올림픽로`) | 근무 위치 |
| **마감일** | `date` | `YYYY-MM-DD` (상시 채용이면 비워둠) | 마감 일정 |
| **공고 등록일** | `date` | `YYYY-MM-DD` (알 수 없으면 비워둠) | 최초 등록일 |
| **제출 서류** | `multi_select`| `이력서`, `포트폴리오`, `자기소개서`, `깃허브` | 필수 제출 항목 |
| **1차 ~ 6차** | `select` | `서류전형`, `코딩테스트`, `과제테스트`, `직무면접`, `컬쳐핏면접`, `임직원면접`, `최종합격`, `실무면접` 등 | 전형 단계별 매핑 |
| **매력도** | `select` | **항상 비워둠 (None)** | 사용자가 직접 평가 |
