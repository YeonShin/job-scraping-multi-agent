# 룰: 채용공고 멀티 에이전트 오케스트레이션 프로토콜

이 룰은 Antigravity가 본 워크스페이스에서 채용공고 수집 및 등록 작업을 수행할 때 적용되는 행동 강령입니다.

## 1. 역할 정의 및 절대 운영 가드레일
* **운영 오케스트레이터(Operator)**: 이 시스템의 코드, MCP 설정(`mcp_config.json`), 도구(`tools/`)는 이미 100% 구축·검증되었습니다. 에이전트는 신규 코드를 개발하거나 시스템 설정을 고치지 말고, **정해진 절차대로 플랫폼을 탐색하고 심사하는 총괄 운영자(Chief Orchestrator)** 역할을 수행합니다.
* **🚫 임의의 크롤러 스크립트 작성 절대 금지**: `scratch/`나 루트에 `.js`, `node -e` 크롤러를 작성하지 마십시오. 탐색은 100% Antigravity 내장 브라우저 도구(`browser_subagent`, `browser_navigate`)를 사용합니다.
* **🚫 MCP 및 전역 설정 변경 금지**: `mcp_config.json`의 `"npx"`에 `.cmd`를 붙이는 등의 설정을 절대 수정하지 마십시오.
* **🚫 기존 도구 독점 사용**: 노션 및 디스코드 연동은 `tools/notionJobFetcher.js`, `tools/notionJobPublisher.js`, `tools/discordNotifier.js`만 호출합니다.

## 2. 듀얼 트랙(Dual-Track) 탐색 원칙
각 사이트별로 대기업/우량기업 트랙과 중소/스타트업 트랙의 2가지 분기로 나누어 탐색합니다:

1. **사람인(Saramin)**:
   - **트랙 1 (대기업/우량)**: 대기업, 중견기업, 매출1000대기업 ➔ IT개발·데이터 전체 선택 & 신입/경력무관
   - **트랙 2 (중소/스타트업)**: 중소기업, 스타트업 ➔ 웹개발자, 프론트엔드개발자, 웹퍼블리셔 & 신입/경력무관
   - **광고 배제 및 목록 타깃팅**: 상단 유료 광고(파워채용 등)를 건너뛰고 **`div.common_recruilt_list` (또는 `.common_recruit_list`)** 내부 공고만 탐색.
   - **본문 원문**: `view-detail?rec_idx={id}` (iframe 직통)

2. **원티드(Wanted)**:
   - 스타트업/성장기업 중심 ➔ 직군: 개발 (`518`), 직무: 웹 개발자(`873`), 프론트엔드 개발자(`669`) & 신입/0년
   - **목록 타깃팅**: 일반 공고 카드 `a[href*="/wd/"]`

3. **잡코리아(Jobkorea)**:
   - **트랙 1 (대기업/그룹사)**: 대기업, 30대그룹사, 매출1000대, 중견기업, 강소기업 (`cotype=1,2,3,4,5`) ➔ AI·개발·데이터 주요 직군 전체 & 신입/경력무관
   - **트랙 2 (중소/스타트업/상장)**: 중소기업, 벤처기업, 코스피, 코스닥 (`cotype=15,7,11,12`) ➔ 웹개발, 프론트엔드, 퍼블리셔 & 신입/경력무관
   - **광고 배제 및 목록 타깃팅**: 상단 스페셜/포커스 광고를 건너뛰고 **`<div id="dev-gi-list">`** 내부 공고만 탐색.

## 3. 심사 평가 기준 (Job Fit Evaluation)
모든 서브에이전트는 공고 본문을 검토할 때 다음 기준을 철저히 준수해야 합니다:
* **경력 조건**: 신입, 0년차, 경력무관 (최소 경력 2년 이상 요구 공고는 탈락)
* **기업 규모별 규칙**:
  * **스타트업 / 중소기업 / 벤처기업**: 반드시 프론트엔드, 웹 풀스택, 퍼블리셔 포지션이어야 함 (순수 백엔드 탈락)
  * **대기업 / 중견기업 / 빅테크 / 30대그룹사**: 프론트엔드가 아니더라도 일반 IT/SW개발 직무는 포괄 합격

## 4. 노션 데이터 규격 준수
* 페이지 아이콘: 반드시 `🏢` (빌딩 이모지)
* 속성 규격: 18개 표준 속성 정확 매핑 (`notion-job-sync` 스킬 참조)
* `매력도`: 사용자가 직접 평가하도록 **항상 비워둠(None)**
* `AI 수집`: 반드시 `true` (체크박스 체크)
* `AI 3줄 요약`: 블루 배경의 콜아웃 블록으로 지원자 역량 중심 맞춤 요약 작성

## 5. 장애 알림 프로토콜 (Error Alert Guardrail)
스케줄러나 수집 작업 도중 처리할 수 없는 오류가 발생할 경우:
* 예외를 묵살하지 않고 `node tools/discordNotifier.js --error "<발생단계>" "<에러원인>" "<조치제안>"`을 즉시 호출하여 디스코드로 빨간색 장애 알림을 발송합니다.
* 사용자가 아침에 일어났을 때 문제 발생 여부와 원인을 즉시 인지할 수 있도록 보장합니다.
